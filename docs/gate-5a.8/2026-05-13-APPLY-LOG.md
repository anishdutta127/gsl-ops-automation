## Decisions (Anish, 2026-05-14)

Three taste calls were surfaced before the apply ran. The chosen policies are reflected in `decisions.json`.

### Decision 1, CONFLICT handling

**Choice:** Apply refresh on all conflicts.

The diff surfaced 18 rows where the refresh contradicted a non-null live field, mostly contract value revisions, student count updates, and a handful of trainer model / end date corrections. Anish chose to trust Pranav's newer numbers across the board rather than default to keep-current. The reasoning: Pranav is the source-of-truth for the sales sheet, and the live data was the gsl-mou-system cutover snapshot taken weeks earlier; refresh values are by definition newer.

**One regression now archived in audit:** R7 Mutahhary Public School Baroo `studentsActual` went from 400 to 0. Pranav probably left the cell blank where it had previously read 400. The audit entry on `MOU-STEAM-2627-001` records the change with `before: { studentsActual: 400 }, after: { studentsActual: 0 }, notes: source: pranav-refresh-2026-05-13`. Flag for Pranav follow-up: confirm whether 400 was wrong or whether the 0 is a placeholder.

### Decision 2, Sale Amount = 0 rows

**Choice:** Apply (fill student counts).

Two existing FY 26-27 MOUs (Jnana Bharathi English School and Mahrishi Dayanand School) had `contractValue: 0` in live data. The refresh added `studentsMou` (200, 220) and kit-sent status without filling the contract value. The other zero-sale rows (Empyrean R50 / R51 at 10800 and 47500 are not zero in the refresh; the audit's zero callout was about `kits-sent="Done"` with low contract value, which still satisfies the policy).

The two zero-sale UPDATE rows applied normally and stay flagged via `MOU.importNotes` for Pranav to fill in the missing sale amount. The needs-review flag is set on the parsed.json record so a future audit query can grep them out.

### Decision 3, Multi-product schools

**Choice:** Continuation = always new MOU.

Three schools have multiple product lines on the refresh:

- Empyrean School: R50 Bootcamp 9 students 10800 + R51 Bootcamp 19 students 47500.
- Contai Public School: R68 GSL-T 450 students 1099350 + R69 GSL-T 150 students 318600.
- Swarnim International School: R70 Bootcamp 250 students 531000 (matched existing `MOU-STEAM-2627-037`) + R71 AIQ 250 students 413000.

The diff classifier already handled these correctly: R70 Swarnim matched the existing 037 by trainer model + contract fingerprint; the other continuation rows had no FY 26-27 match and got classified as NEW. The apply created six new MOUs and updated 037; this matches Anish's policy.
